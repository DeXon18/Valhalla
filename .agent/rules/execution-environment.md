# Entorno de ejecución

Antes de modificar:

- leer `docs/v2/CURRENT.md`;
- confirmar workspace;
- confirmar rama;
- comprobar `git status`.

Para trabajo de Development, usar:

/opt/web-projects/Valhalla/development

Development usa `develop` como rama integrada.

No trabajar directamente sobre `main`.

Production solo se prepara o modifica cuando CURRENT lo autorice expresamente y exista el entorno correspondiente.

Si el entorno observado no coincide con la tarea autorizada, detener cambios y comprobar el estado antes de continuar.
