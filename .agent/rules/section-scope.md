# Alcance de CURRENT

`docs/v2/CURRENT.md` contiene la única tarea autorizada.

Antes de implementar:

- identificar el resultado observable;
- respetar Scope incluido;
- respetar Scope excluido.

El contenido de `VALHALLA.md`, `PRODUCT.md`, `DESIGN.md`, `SECTIONS.md` y `BACKLOG.md` aporta contexto, pero no amplía CURRENT.

Una idea útil fuera de CURRENT debe ir a BACKLOG y no implementarse.

Si una necesidad nueva resulta imprescindible para completar CURRENT, aplicar únicamente el cambio mínimo necesario.

Si cambia materialmente el alcance, requiere decisión del propietario.
