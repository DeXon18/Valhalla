# Inicio de sesión

## Objetivo

Empezar una sesión de trabajo con el contexto correcto y sin ampliar el alcance.

## Procedimiento

1. Leer `RUMBO.md`.
2. Leer `docs/v2/CURRENT.md`.
3. Identificar el resultado observable autorizado.
4. Leer `AGENTS.md`.
5. Confirmar:
   - workspace;
   - rama;
   - `git status`.
6. Consultar únicamente los documentos necesarios para CURRENT.
7. Seleccionar solo las herramientas necesarias para la tarea actual.
8. Empezar una única tarea.

## Detenerse si

- CURRENT no está claro;
- el workspace o la rama no corresponden;
- existen cambios previos no entendidos;
- la acción necesaria queda fuera del scope autorizado.

BACKLOG, PRODUCT, DESIGN y VALHALLA aportan contexto, pero no amplían CURRENT.
