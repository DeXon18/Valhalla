# Valhalla

## Identidad

Valhalla es una aplicación web self-hosted para registrar entrenamiento de fuerza, rutinas, ejercicios, progresión, historial, métricas corporales y evolución.

Versión inicial objetivo: `0.1.0`.

## Principios de producto

- Aplicación web SSR responsive.
- Mobile-first, con desktop como experiencia de primera clase.
- Español e inglés desde la primera interfaz.
- La misma aplicación sirve gimnasio y entrenamiento en casa cuando las funciones correspondientes existan.
- El producto crece mediante incrementos visibles y utilizables.
- Las funciones futuras del mapa no forman parte de `CURRENT` hasta que el propietario las autorice.

## Núcleo funcional previsto

El mapa de producto contempla, por etapas: base técnica y app shell, web pública, autenticación, dashboard, perfil, catálogo de ejercicios, rutinas, motor de entrenamiento, historial y evolución, ajustes y datos. Otras capacidades quedan para fases posteriores o backlog según `VALHALLA.md`.

## Fuente de autoridad

- `RUMBO.md`: disciplina general de trabajo.
- `docs/v2/CURRENT.md`: única tarea autorizada ahora.
- `VALHALLA.md`: mapa maestro del producto y plan de ejecución.
- `DESIGN.md`: identidad visual y UX.
